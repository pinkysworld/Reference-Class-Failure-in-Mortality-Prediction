# Reference-Class Failure in Mortality Prediction — Reproducibility Package

This repository reproduces the synthetic experiment reported in the manuscript
*"Reference-Class Failure in Mortality Prediction: A Synthetic Study of Irreducible
Uncertainty in End-of-Life Prognostic Models."*

Two patient regimes share overlapping observable features but are generated by
different conditional outcome mechanisms (concept shift), governed by an
unmeasured latent terminal state. Supervised models are trained only on the
reference regime and evaluated in both regimes. The experiment shows that error
on the novel regime stays high as reference data accrue (data-insensitive error),
that models remain confident on novel cases (pseudo-precision), and that the
failure is difficult to detect in feature space and is not corrected by
confidence-based abstention.

## Requirements

- Python 3.10+
- See `requirements.txt`

## Quick start

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run_reference_class_experiment.py --seeds 20
```

The run is deterministic (fixed random seeds) and writes to `outputs/`,
`figures/`, and `tables/`. A full 20-seed run completes in a few minutes on a
laptop.

## Sensitivity analysis

`tables/table_s3_sensitivity_analysis.md` reports three variants that separate
the contributing causes of the main result:

- **main** — the headline novel regime (concept shift plus a mild feature shift; prevalence ≈ 0.76).
- **concept_shift_only_no_feature_shift** — identical feature distribution to the reference regime (zero covariate shift); error remains elevated, isolating concept shift.
- **prevalence_matched_novel** — the novel-regime base rate forced to match the reference (≈ 0.35); error remains elevated, showing the result is not a base-rate artifact.

In all three variants the model's Brier score is far above the achievable
(Bayes-optimal) floor for that variant.

## Interpretation and scope

This is a synthetic stress test, not an estimate of real-world mortality. It
isolates a mechanism under a known data-generating process. It does not estimate
how often, or how severely, reference-class failure occurs in real care; that
requires empirical study on clinical cohorts.
